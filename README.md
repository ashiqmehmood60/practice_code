# 🎯 Number Guessing Game

A beginner-friendly Number Guessing Game built using Python and Streamlit.

The computer randomly selects a number between **1 and 100**. The player has to guess the correct number. After each guess, the game provides a hint.

## ✨ Features

- Random number generation
- Interactive guessing game
- Too high / Too low hints
- Attempt counter
- Play Again option
- Command-line and Streamlit versions

## 📁 Project Structure

```text
guess-game/
├── guess_game.py

```

## 🛠️ Requirements

- Python 3.8 or later
- Streamlit

Install Streamlit:

```bash
pip install streamlit
```

## 🚀 How to Run

### 1. Python Version

```bash
python guess_game.py
```

### 2. Streamlit Version

```bash
streamlit run app.py
```

## 🎮 How to Play

1. Start the game.
2. Enter a number between 1 and 100.
3. If your guess is too low, try a bigger number.
4. If your guess is too high, try a smaller number.
5. Find the correct number to win!
6. Click Play Again to start a new round in Streamlit.
